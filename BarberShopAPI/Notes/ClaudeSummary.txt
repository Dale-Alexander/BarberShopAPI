Project: BarberShopAPI — ASP.NET Core + EF Core + SQL Server backend (BarberShopAPI/), React frontend (BarberShop/). Booking system for a barbershop with three roles: ADMIN and BARBER (login with email+password), CUSTOMER (no account, just books). Fresh repo, zero git commits so far — everything is currently uncommitted.

Booking flows:
- Admin/barber books for a walk-in: POST /create-admin-booking — no email required, booking created directly as COMPLETED.
- Customer self-books: POST /create-pending creates a PENDING booking holding the slot, then either POST /confirm-cash (pay at store) or POST /payment-intent → Stripe card flow → POST /api/webhook finalizes on payment_intent.succeeded.
